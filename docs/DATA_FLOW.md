# 🗺️ Карта переходов данных по этапам цеха

Построено автоматически по реальному коду: `src/core/types/index.ts` (STAGE_ORDER),
`src/transfer/apply.ts` (кейсы пакетов), комнаты в `src/stages/`.
Обновлено: 2026-10-28. Все переходы офлайн: QR / текст / Bluetooth, формат LIP-пакета.

## Основная цепочка техпроцесса

```
📦 Склад материалов
   │  (компоненты для замеса)
   ▼
🧪 КОМНАТА ЗАМЕСОВ
   │  пакет mix-batch (+ mix-component, mix-recipe — базы master→slave)
   ▼
🖌️ НАМАЗКА (нанесение покрытия)
   │  принимает coating-mix (данные замеса: вязкость, СВ, ρ → расчёт зазора фильеры и шнека)
   │  пакет roll-spec — рулон с намазки технологу (master): название замеса,
   │  толщина до прокатки, длины участков, стороны A/B
   ▼
🔄 КАЛАНДРИРОВАНИЕ (ПРОКАТКА)
   │  технолог уточняет параметры: толщина после, нагрев, t°, давление (т), обрезка кромки
   │  журнал оператора: фактические зазоры валков, общая длина, дефекты
   │  пакет calender-result → нарезка (рулоны без дефектов переходят автоматически)
   ▼
✂️ НАРЕЗКА ЭЛЕКТРОДОВ
   │  принимает cutting-roll (рулон + задание технолога: полосы/призматические,
   │  тип покрытия, длина электрода)
   │  расчёт выхода пластин; журнал cut-run (годные/дефектные/обрывы)
   │  пакет cut-run → сортировка (название партии + количества)
   ▼
📏 СОРТИРОВКА ЭЛЕКТРОДОВ
   │  приходит название партии с нарезки; технолог задаёт спецификацию sort-spec
   │  (параметры из КД: толщина, масса; реестр дефектов: критичные/некритичные)
   │  разнос годных по категориям; журнал sort-run
   │  пакет sort-run → сборка
   ▼
🔋 СБОРКА ЭЛЕМЕНТОВ (6 станций, каждая — отдельный файл)
   │  B-c1 LiElectrodesStation  — отрицательные литиевые электроды
   │  B-c2 ZStackingStation     — укладка (Z-стек)
   │  B-c3 WindingStation       — скрутка цилиндрических блоков
   │  B-c4 CrimpCylStation      — зиговка + точечная + УЗ сварка крышки (цилиндрические)
   │  B-c5 UsPrismaticStation   — УЗ сварка крышки (призматические)
   │  B-c6 LaserPrismaticStation— лазерная сварка (призматические)
   │  ★ Номер аккумулятора (serialRange: префикс + начало..конец) рождается здесь
   │  пакет assembly-run (с номерами АК) → обе заливки
   ▼
💧 ЗАЛИВКА ЭЛЕКТРОЛИТА — ДВА ПОМЕЩЕНИЯ (одна комната-компонент FillRoom)
   ├─ ELECTROLYTE      — бокс СУХОЙ КОМНАТЫ   ── пакет fill-run ──┐
   └─ ELECTROLYTE_705  — бокс 7 этаж, к.5     ── пакет fill-run ──┤
      ★ номера АК мигрируют транзитом через обе заливки           │
   ▼                                                              │
🗜️ ВАЛЬЦОВКА (после заливки на 7 этаже)                           │
   │  принимает walzing-in (залитые ячейки с номерами АК)          │
   │  журнал walz-run (обжим) ────────────────────────────────────┤
   ▼                                                              ▼
⚡ ФОРМИРОВАНИЕ (ЧЦЦ) ← связь с сухой комнатой: formation-in
   │  приём партий: formation-in (номера АК подхватываются автоматически)
   │  режим: ток (А), напряжение (В), количество циклов
   │  дата начала формировки; результат: ёмкость 5-го цикла (А·ч),
   │  кулоновская эффективность (%); журнал formation-run
   ▼
✅ Финиш цепочки (комната «Старение» удалена из проекта по решению от 2026-10-28)
```

## Переходы по типам пакетов (из src/transfer/apply.ts)

| Пакет | Откуда → Куда | Что переносит |
|---|---|---|
| `task` / `result` | начальник → мастер → технолог → работник | задания и результаты (цепочка подчинения) |
| `journal`, `comment`, `user` | любое ↔ любое | журналы, комментарии, пользователи (forced = master→slave) |
| `mix-batch` | Замесы → Намазка | состав замеса, граммовки, режим |
| `mix-component`, `mix-recipe` | master → slave | базы компонентов и стандартных замесов |
| `coating-mix` | Замес → Намазка | вязкость, СВ, ρ пасты (для расчёта зазора/шнека) |
| `roll-spec` | Намазка → Технолог | рулон: замес, толщина до прокатки, длины участков |
| `calender-result` | Каландр → Нарезка | зазоры, длина, дефекты, параметры прокатки |
| `cutting-roll` | Каландр → Нарезка | рулон + задание технолога (тип электрода, длина) |
| `cut-run` | Нарезка → Сортировка | название партии, годные/дефектные |
| `sort-spec` | Технолог → Сортировка | категории КД: толщина, масса, реестр дефектов |
| `sort-run` | Сортировка → Сборка | партия по категориям |
| `assembly-run` | Сборка → Заливка×2 | ★ номера АК (serialRange), станции, брак |
| `electrolyte-in` | (подготовка приёма) → Заливка | входящая партия залитых ячеек |
| `fill-run` | Заливка → Вальцовка / Формирование | залитые ячейки с номерами АК |
| `walzing-in` | Заливка (7 эт.) → Вальцовка | ячейки под обжим |
| `walz-run` | Вальцовка → Формирование | обжатые ячейки, номера АК |
| `formation-in` | Заливка (сухая)/Вальцовка → Формирование | партия на ЧЦЦ с номерами АК |
| `formation-run` | Формирование → master | режим, дата, ёмкость 5 цикла, Кулон отдача |
| `defect-entry` | любая комната → master | фиксация дефектов |
| `chat` | mesh-ретрансляция | сообщения чата цеха (TTL=5) |

## Master-slave
- Пакеты с флагом `forced` применяются безусловно (принудительная допись master'ом).
- Обычные пакеты применяются, если `updatedAt` новее локальной записи.
