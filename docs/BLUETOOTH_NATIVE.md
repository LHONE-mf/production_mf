# Нативный BLE-модуль (Android)

## Что это
Плагин `BleBridgePlugin.java` (Capacitor, системный Android API Bluetooth LE).
Решает главную проблему веб-библиотеки: теперь приложение может быть ОДНОВРЕМЕННО
и передатчиком, и приёмником без ручного выбора устройства.

## Как работает передача (офлайн, без интернета)
1. **Передатчик** нажимает «Раздать пакет»:
   - включает BLE-advertising: сервис FF60 + заголовок пакета ("LIPW" + длина + CRC) в serviceData;
   - поднимает GATT-сервер с характеристикой чтения FF61 — по запросу отдаёт весь пакет.
2. **Приёмник** жмет «Режим приёма»:
   - сканирует эфир (фильтр по UUID сервиса);
   - видит заголовок → подключается → читает FF61 → проверяет длину и CRC;
   - применяет пакет в базу и отключается. Всё автоматически.
3. **Mesh**: принявший пакет устройство может раздать его дальше той же кнопкой;
   дедупликация по длине+CRC защищает от «эха» (пакет не принимается дважды).

## Запасные пути
- Если нативный плагин недоступен (старый APK), отправка/приём идут через
  библиотеку @capacitor-community/bluetooth-le (ручной выбор устройства).
- QR и текст работают всегда (веб, iOS, ПК).

## iOS
Ограничения Apple: сторонние приложения не могут одновременно рекламировать
сервис и принимать соединения в фоне. Web Bluetooth в Safari тоже нет.
На iPhone штатные способы — QR и текст; фоновый BLE-приём возможен только
через нативное приложение на Swift (отдельная задача, не входит в PWA/APK).

## Требования Android
- Разрешения BLUETOOTH_SCAN / BLUETOOTH_CONNECT / BLUETOOTH_ADVERTISE (Android 12+)
  или BLUETOOTH / BLUETOOTH_ADMIN (до Android 11) — уже в манифесте;
- приложение должно быть открыто на экране синхронизации во время передачи.
