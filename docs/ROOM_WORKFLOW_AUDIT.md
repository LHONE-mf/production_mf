# Room workflow evidence — 2026-11-11

Inventory: `src/stages/registry.ts` and `StageRouter.tsx`, inspected at
`ff2c97e` and updated by the coating persistence slice. This is a code audit,
not a factory acceptance report. **Code** means a control/write path exists;
**unit/IndexedDB/component/browser** mean that specific automated check ran.
No room has physical OnePlus, equipment, stock reconciliation or QA acceptance
from this audit. Source files are under `src/stages/<room>/` unless noted.

All rooms use local Dexie records and the current local account. Local account
roles do not grant server authority. Comments use `stageComments`; generic work
entries use `journal`; task visibility uses `listVisibleTasks`. Local work must
remain available offline. QR/text packets are explicit transfers, not server
synchronization or proof of physical consumption. Generic save/packet paths
outside coating still need failure, duplicate and restart tests.
