### Требования к комнате нарезки (со слов пользователя)

**Вход (приходит с каландра, пакет `calender-result` уже формируется кнопкой «✂️ На нарезку»):**
- рулон с прокатки (RollSpec + CalenderRun: толщина после прокатки, длины, нагрев, давление, обрезка кромки, дефекты);
- задание технолога (тип электрода): **полосы для цилиндрических** или **призматические пластины**; тип электродного покрытия; для цилиндрических — длина электрода (мм).

**Инструменты комнаты:**
- приём входящих рулонов (QR/текст/BLE через apply.ts, case 'cutting-*' добавить);
- расчёт выхода: сколько пластин/полос получается из рулона (ширина полотна × длина → площадь → шт);
- журнал нарезки: партия, кол-во годных, кол-во с дефектами, виды дефектов, обрывы.

**Выход:**
- передача результатов на участок сортировки (партия: тип, количество годных/дефектных, id рулона).
